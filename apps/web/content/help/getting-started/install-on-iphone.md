# Put the board on your phone's home screen

The board runs in a browser, but it is built for **standalone** mode — added to
your home screen, where iOS gives it the whole display and no address bar.

## On iPhone

1. Open [board.coach.vision](https://board.coach.vision/) in **Safari**. It has
   to be Safari; Chrome on iOS cannot add a web app to the home screen.
2. Tap the **Share** button (the square with the arrow).
3. Scroll down and tap **Add to Home Screen**.
4. Name it whatever you'll recognise at the rink, then tap **Add**.

Open it from that icon from now on. You'll get the full screen, the layout will
sit correctly above the home indicator, and it will keep working if the rink
wifi drops — the board itself needs no network once loaded.

## On Android

Chrome shows an **Install app** item in its menu on the same page.

## Why it matters

In a browser tab, Safari reserves a band at the bottom for its toolbar that no
web page can reclaim. Standalone mode is the only way to get the whole sheet of
ice on screen, which is the difference between reading a drill at arm's length
and squinting at it.
