# Give-and-Go to the Net

The simplest way to show a ten-year-old what *support* means. F1 gives it up
and immediately goes — the pass is only good if the passer moves after making
it. Run it both sides so nobody only ever practises their forehand.

```drill
RINK half
TITLE Give-and-Go to the Net
DESC F1 passes to F2 on the wall, drives the middle, takes the return and shoots.
NOTES
| ## Coaching points
|
| 1. **Pass and go.** The give is worthless if the feet stop.
| 2. F2 catches it moving, one-touch back into space — not at F1's skates.
| 3. Shoot in stride. No extra stickhandle at the top of the circle.
|
| - Run both sides so it isn't a forehand-only drill.
END NOTES
PIECE N2 net 183 42.5 face=180 goalie
PIECE F1 player 120 62 F1
PIECE F2 player 132 74 F2
PATH F1 L 142,52 L 158,44
PIECE PK1 puck 120 62 on=F1 pass=1:F2@0 shoot=2:F1
STEP at=0 "**F1** gives it up and immediately goes"
ITEM puck count=6
```
